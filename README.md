# LinguaFlow V0.1

Bộ khung webapp học ngôn ngữ AI, thiết kế đa ngôn ngữ ngay từ đầu.

## Chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Deploy Vercel

1. Đưa toàn bộ code lên GitHub repository.
2. Vercel > Add New Project > Import repository.
3. Deploy.

## Supabase

File `supabase/schema.sql` đã chuẩn bị schema nền. Chưa cần chạy cho đến bước kết nối database/auth.
